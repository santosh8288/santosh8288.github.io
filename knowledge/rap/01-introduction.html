What is RAP?

The ABAP RESTful Application Programming Model (RAP) is SAP’s modern development model for building transactional and service-oriented applications. It brings data modeling, transactional behavior and service exposure into a consistent business-object programming model.

Why RAP?

RAP encourages a clear separation between data semantics, transactional behavior and service consumption. This reduces the need to hand-build infrastructure that the framework can provide.

Core building blocks

CDS data model; behavior definition; behavior implementation; Entity Manipulation Language (EML); service definition and binding; and Fiori Elements consumption.

Architect’s perspective

Start with the business process and business object. Do not start with a UI screen or a copy of an older ABAP pattern.
