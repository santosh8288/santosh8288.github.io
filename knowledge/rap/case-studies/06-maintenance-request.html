Plant Maintenance Request — EML

A maintenance request demonstrates EML for reading a RAP business object and performing a transactional modification through the behavior contract.

EML is especially useful in application logic, tests and orchestration where one RAP business object needs to be manipulated without bypassing its transactional behavior.

Read with EML

READ ENTITIES OF ZI_MaintRequest IN LOCAL MODE
  ENTITY MaintenanceRequest
  FIELDS ( RequestID Equipment Priority Status )
  WITH VALUE #(
    ( %key-RequestUUID = lv_uuid ) )
  RESULT DATA(requests).

Update with EML

MODIFY ENTITIES OF ZI_MaintRequest IN LOCAL MODE ENTITY MaintenanceRequest UPDATE FIELDS ( Priority ) WITH VALUE #( ( %tky = requests[ 1 ]-%tky Priority = 'HIGH' ) ) FAILED DATA(failed) REPORTED DATA(reported).

Why EML

The intent is to interact with the business object, not directly update its persistence table. That allows the RAP behavior contract to remain the source of truth for transactional rules.

Production note: The code is intentionally a teaching/reference skeleton. CDS entity names, database fields, message classes, authorization implementation, released APIs and syntax can vary by ABAP platform/SAP S/4HANA release. Activate and test against your target system before treating it as production code.
