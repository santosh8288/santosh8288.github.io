Supplier Invoice — Validation & Determination

A supplier invoice demonstrates two classic RAP rules: derive a value automatically and block activation when business data is invalid.

Scenario: the invoice contains net amount and tax percentage. RAP calculates tax amount and gross amount, while validation prevents an invoice with a negative amount or invalid tax rate from being saved/activated.

CDS

define root view entity ZI_SupplierInvoice
  as select from zsup_invoice
{
  key invoice_uuid as InvoiceUUID,
      invoice_no   as InvoiceNumber,
      supplier_id  as Supplier,
      net_amount   as NetAmount,
      tax_rate     as TaxRate,
      tax_amount   as TaxAmount,
      gross_amount as GrossAmount,
      currency_code as Currency
}

Behavior

managed implementation in class zbp_i_supplierinvoice unique;
strict ( 2 );

define behavior for ZI_SupplierInvoice alias Invoice
persistent table zsup_invoice
lock master
{
  create;
  update;
  delete;

  determination calculateTax on modify
    { field NetAmount, TaxRate; }

  validation validateAmounts on save
    { create; update; }
}

Determination

METHOD calculateTax.

  READ ENTITIES OF zi_supplierinvoice IN LOCAL MODE
    ENTITY Invoice
    FIELDS ( NetAmount TaxRate )
    WITH CORRESPONDING #( keys )
    RESULT DATA(invoices).

  MODIFY ENTITIES OF zi_supplierinvoice IN LOCAL MODE
    ENTITY Invoice
    UPDATE FIELDS ( TaxAmount GrossAmount )
    WITH VALUE #(
      FOR invoice IN invoices
      ( %tky = invoice-%tky
        TaxAmount = invoice-NetAmount * invoice-TaxRate / 100
        GrossAmount = invoice-NetAmount
                    + invoice-NetAmount * invoice-TaxRate / 100 ) ).

ENDMETHOD.

Validation

METHOD validateAmounts.

  READ ENTITIES OF zi_supplierinvoice IN LOCAL MODE
    ENTITY Invoice
    FIELDS ( NetAmount TaxRate )
    WITH CORRESPONDING #( keys )
    RESULT DATA(invoices).

  LOOP AT invoices ASSIGNING FIELD-SYMBOL().
    IF -NetAmount <= 0 OR
       -TaxRate < 0 OR -TaxRate > 100.

      APPEND VALUE #( %tky = -%tky )
        TO failed-invoice.

      APPEND VALUE #(
        %tky = -%tky
        %msg = new_message_with_text(
          severity = if_abap_behv_message=>severity-error
          text = 'Invalid invoice amount or tax rate' )
      ) TO reported-invoice.
    ENDIF.
  ENDLOOP.

ENDMETHOD.
